# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, and keep feedback about the work, not the person. Harassment, insults and personal attacks are not accepted in issues, pull requests or anywhere else the project is discussed.

To report a problem, email hello@focuskept.com. Reports are read only by the maintainer and kept private.
