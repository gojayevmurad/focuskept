## Branding

For branding, logo, icon, email identity, or social-image work, start with
`docs/brand/README.md`. It links the product audit, creative brief, asset/export
specification, source/tool evaluation, and complete integration handoff. The
owner selected direction A and approved kit 1.0.0 for local integration; `brand/`
contains the kit and its manifest records actual review/integration state. Use the manifest rather than
inferring final approval from a recommendation. Use `docs/DESIGN.md` for the existing UI system.
